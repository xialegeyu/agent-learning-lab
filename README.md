# Agent Learning Lab

一个从零开始学习 agent 的 Codex 项目。

这个仓库刻意不包含现成实现代码。目标是把每一次学习都拆成小实验，然后用 Codex/Antigravity 一步步创建、运行、记录和复盘。

## 怎么用

1. 在 Antigravity 中打开这个仓库。
2. 从 `experiments/` 开始创建第一个实验。
3. 每个实验保持小而完整：目标、代码、运行方式、观察结果。
4. 学到一个概念，就提交一次 Git commit。

## 建议目录

```text
experiments/
  001-hello-agent/
notes/
  concepts.md
```

这些目录还没有创建。等你开始第一个练习时再创建，这样项目会真正从你的学习路径长出来。

## 第一个可做的练习

让 Codex 帮你创建 `experiments/001-hello-agent`，目标是：

- 初始化一个最小 Node.js 或 Python agent 项目
- 读取一个命令行输入
- 调用一次模型
- 打印结果
- 写下你观察到的输入、输出和改进点
